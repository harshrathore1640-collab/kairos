# KAIROS — Website

A responsive static website built with HTML, CSS and Vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For best results use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a repository for this business website.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Before publishing
- Replace demo/stock images with the business's approved photos.
- Verify contact details and business location.
- The enquiry form opens WhatsApp and does not store leads or send emails.
- Add a privacy policy if analytics, tracking, or lead storage is later introduced.
- External Google Fonts and Unsplash images need an internet connection.
